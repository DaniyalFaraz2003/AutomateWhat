
# AutomateWhat - WhatsApp AI Pipeline GUI Application

A professional GUI application for automating WhatsApp message processing
using AI models including YOLO for message detection and LLMs for response generation.

Author: Daniyal Faraz
Version: 1.0.0
License: MIT


# Project structure
```
AutomateWhat/
├── main.py                 # Main entry point
├── frontend/               # GUI components
│   └── main_window.py     # Main window implementation
├── backend/                # Core business logic
│   └── ai_service.py      # AI pipeline service
├── config/                 # Configuration files
│   └── settings.py        # Application settings
├── utils/                  # Utility functions
│   └── logger.py          # Logging utilities
├── models/                 # AI model files
├── assets/                 # Static assets (images, icons)
├── docs/                   # Documentation
├── tests/                  # Test files
└── logs/                   # Log files (auto-created)
```

# Features

- Professional GUI interface using tkinter
- Modular architecture for easy maintenance
- Integration with existing WhatsApp AI pipeline
- Model management and status monitoring
- Comprehensive logging system
- Theme support (light/dark)
- Error handling and user feedback


# Installation

1. Ensure Python 3.8+ is installed
2. Install required dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   `python main.py`
